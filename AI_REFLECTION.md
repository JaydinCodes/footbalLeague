# AI Collaboration Reflection

## AI Tool Used

OpenAI ChatGPT was used throughout the development of this project as a software engineering collaborator.


## How ChatGPT Was Used

ChatGPT was used to:

- Break the assessment into implementation phases.
- Discuss the application architecture.
- Review class responsibilities.
- Suggest validation rules.
- Design automated tests.
- Identify edge cases.
- Help debug compilation and runtime issues.
- Review the CLI design.
- Assist with documentation.

## Human Responsibility

ChatGPT suggestions were reviewed before being implemented.

I remained responsible for:

- Understanding the implementation.
- Making final design decisions.
- Running the application.
- Running the automated tests.
- Verifying the historical football data.
- Checking the final output against the expected standings.

## Reflection

The most useful aspect of AI collaboration was using ChatGPT as a second engineering perspective rather than treating it as an automatic code generator.

The development process involved discussing an approach, implementing it, testing it, identifying problems, and then refining the implementation.

This was particularly useful when designing the separation between the CSV layer, domain model, calculation service and command-line interface.

The AI also helped identify additional test cases and edge cases that might otherwise have been missed.
