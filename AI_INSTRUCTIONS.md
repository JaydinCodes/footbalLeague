# AI Development Instructions

This project was developed with assistance from OpenAI ChatGPT.

## Project

Football League Standings Calculator for the SPAN Associate Software Engineer take-home assessment.

## Technical Requirements

- Java 21
- Maven
- JUnit
- CSV input and output
- Command-line execution
- Platform-independent Java APIs

## Engineering Principles

- Keep business logic separate from I/O.
- Keep classes focused on a single responsibility.
- Validate invalid input early.
- Prefer simple solutions over unnecessary dependencies.
- Write automated tests for important business rules.
- Ensure the application can be explained and understood by the developer.

## AI Usage

ChatGPT may be used as a development collaborator for:

- Architecture
- Implementation guidance
- Debugging
- Refactoring
- Test design
- Code review
- Documentation
- Identifying edge cases

AI-generated suggestions must be reviewed, understood and tested before being included in the project.
